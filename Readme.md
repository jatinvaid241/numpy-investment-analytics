# Investment Return Analysis using NumPy

## Project Overview
This project analyzes historical annual returns of Stocks, T.Bills, and T.Bonds using NumPy.

## Dataset
The dataset contains yearly investment returns for Stocks, T.Bills, and T.Bonds.

## Tools Used
- Python
- NumPy

## Analysis Performed
- Descriptive statistics (mean, max, min, std)
- Risk–return tradeoff analysis
- Cumulative return analysis
- Year-wise best investment evaluation
- CSV summary generation

## Key Insights
- Stocks provide the highest long-term returns.
- T.Bills are suitable for risk-averse investors.
- Bonds balance risk and return.

## Conclusion
Stocks are the best long-term investment despite short-term volatility.
